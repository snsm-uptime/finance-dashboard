topic: Button component system redesign (BaseButton + Primary/Accent/Ghost variants)
updated: 2026-09-03T00:18
---

- (decision) Primary = moss {colors.accent}. Accent = new distinct color: light #4356A3, dark #ADBDFF.
- (decision) Accent hover inverts like Primary: fill->transparent, border stays accent, text->accent.
- (decision) Ghost hover: border/text shift muted->accent, fill stays none.
- (decision) Disabled state: uniform opacity 0.55 dim across all variants, cursor not-allowed, hover suppressed.
- (decision) Primary hover: fill solid primary, label text becomes transparent knockout (background-clip cutout), page shows through glyphs.
- (decision) BaseButton shadow: none at idle, soft elevation lift (shadow + translateY(-1px)) on hover, flattens on active.
- (decision) BaseButton needs sm/md/lg size variants (not single fixed size).
- (decision) BaseButton adds optional iconLeft/iconRight ReactNode slots.
- (decision) case prop is text-transform only (uppercase|lowercase|none), default none, label string untouched.
- (decision) BaseButton adds loading boolean: spinner replaces/accompanies label, forces disabled behavior while true.
- (override) Primary label weight: not bold (normal/500), was 600.
- (override) Primary hover knockout must not flash white on enter/exit — background-clip:text swap needs a flicker-safe implementation (avoid animating color+background-clip together; isolate compositing layer).
- (override) Accent idle/hover swapped from original decision: idle = outline (border+text=accent, fill=none), hover = filled (fill=accent, text=on-accent). Reason: filled-by-default read as already-hovered/active next to Primary's outline idle.
- (override) Primary knockout/clip-text hover abandoned (persistent webkit flicker, unfixable in this pass). Primary now mirrors Accent's mechanic exactly: idle=outline (border+text=primary, fill=none), hover=filled (fill=primary, text=on-primary). Primary and Accent are now the same interaction pattern, differing only by color token.
- (override) Ghost hover color changed from accent to primary: border+text shift muted->primary on hover, fill stays none.
- (override) BaseButton needs explicit line-height (1.2) + flex centering (inline-flex, align-items:center, justify-content:center) — default button line-height was leaving label not vertically centered, especially once icon slots are added.
- (event) DESIGN.md and EXPERIENCE.md drafted; button-states.html promoted to mockups/.
- (event) doc_standards applied (structure + prose editorial review). Spines finalized.
