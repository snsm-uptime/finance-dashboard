01 · Why this spine

Consistency contract for a thin vertical slice

Self-hosted web app: upload → parse → store → shared-expenses. The spine fixes only the calls two story branches could invent incompatibly — paradigm, boundaries, ownership, money, process.

  • Sources: final PRD + EXPERIENCE/DESIGN companions
  • Deliverable: build substrate (+ this deck for future-you)
  • Status: final

02 · Paradigm

Hexagonal — ingest is a pipeline inside the ring

Domain owns lists, cards, dedup, commit, settle math. Bank PDF libs and Next.js never enter domain.

  • Detect → split → parse → normalize → stage → review → commit
  • Not pipes-and-filters-first (lists would become afterthoughts)

03 · Stack

Compose: db + FastAPI api + Next.js ui

  • api Python 3.12 · FastAPI · SQLAlchemy 2 · Alembic · pdfplumber
  • ui Next.js 16.2 standalone · react-pdf · @use-gesture · Warm Balance
  • db PostgreSQL 16 · volume outside repo
  • Streamlit / Node-primary API rejected for BAC parse + gesture review
  • In-process parse on api — no Redis worker in v1

04 · Hard boundaries

Dependency shortlist (AD-1)

Allowed

  • Next → HTTP API only
  • Adapters return CanonicalLine
  • Repos persist Postgres

Forbidden

  • Next → SQLAlchemy / parsers
  • Bank adapter → commit/lists
  • Domain → frameworks / pdfplumber

Auth: httpOnly Secure cookie, same-origin via proxy/BFF — never Bearer in localStorage (AD-8).

05 · Data lifecycle

Session stages · Batch commits · Quarantine survives

  • CanonicalLine shared staging↔ledger (AD-16)
  • Domain owns dedup identity (AD-18)
  • FX CRC materialized at commit from BCCR (AD-7)

06 · Product rules that stop fights

Money, splits, FX, same-price, settle

  • NUMERIC / Decimal only — never float
  • Split remainder → list creator
  • BCCR + nearest-prior fallback + flag; no override; CRC stored at commit
  • Same-price window list-configurable, default ±3 days; server-side candidates
  • v1 settle = computed shares only; inter-member transfer line type reserved (no payment ledger)
  • List ACL = membership; cards are first-class for IBAN registration

07 · How we build

Branches · SemVer · TDD · CI

  • Branch per story: <type>/<epic>/<us-id>
  • One app SemVer: vMAJOR.MINOR.PATCH
  • Hard red→green for parsers/domain; UI test-after with coverage floor
  • Merge to main only when CI green: lint · api pytest+goldens · ui typecheck/lint · critical ui tests
  • CI fixtures = synthetic geometry PDFs; real statements outside repo
