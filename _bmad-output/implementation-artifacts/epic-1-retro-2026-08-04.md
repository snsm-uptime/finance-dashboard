## Challenges

- **Comprehension gap at story close:** Behavior was proven (tests/AC); how components interact and *why* that shape was chosen was not explained before done. Sebas wants a short how/why overview before stories close.
- **Auth hardening deferred as a class:** Rate limits, session hashing/HMAC, token claim/`expires_at` gaps across 1.2–1.5.
- **Review-closure lag:** Story 1.2 stayed in `review` until late, blocking honest Epic 1 “done.”
- **Hex ports incomplete:** Routes still import concrete adapters (recurring polish debt).
- **Compose pytest ergonomics:** Running pytest inside the API image hit permission issues; host venv + DB worked but was awkward.
- **Membership ACL deferred:** Correct for Epic 1 scope; Epic 2 needs it immediately with little stub runway.

---

## Key insights

1. Green tests ≠ shared mental model of the wiring — teach the interaction map at close.
2. Deferred hardening compounds when the next epic adds invite mail and tokens.
3. Process win to institutionalize: story-close interaction overview (request path, key components, why this shape, what not to break).
4. Epic 2 product direction remains sound; sequencing must absorb prep/loose ends before continuing shared-list work.
